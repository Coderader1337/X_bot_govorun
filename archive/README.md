# Архив одноразовых артефактов

Сюда перенесены файлы, которые **не являются частью работающего бота**.
Их не нужно копировать на VPS и не нужно запускать при обычной эксплуатации.

| Файл | Зачем был | Почему в архиве |
|---|---|---|
| `backfill_july7.py` | Разовый бэкафилл пропущенного окна 7 июля 2026 для твита `2074139935297138972` | Дата и tweet-id устарели; в проде другой parent |
| `tmp_db_stats.py` | Ручной sqlite-запрос к старой БД на VPS | Одноразовый черновик |
| `tmp_first_lead.py` | То же | Одноразовый черновик |
| `reset_slice_cursor.py` | Сдвиг курсора search-бота (`run_bot.py`) на дату | Search-бот на VPS остановлен с 8 июля 2026 |
| `parent_tweet.json` | Кэш parent-твита `2074139935297138972` (@Rusia_HD) | Прод работает с `2079647800636428422` |
| `reply_target_analysis.txt` | Разбор, какие ответы — прямые, какие нет | Исследование июля 2026 |
| `clean_leads.csv` | Выгрузка отфильтрованных лидов | Слепок анализа, не runtime |
| `discovered_leads.csv` | Сырая выгрузка discovery | Слепок анализа, не runtime |

Рабочие точки входа — в корне репозитория: `run_reply_bot.py`, `run_bot.py`, `docker-compose.yml`.
Подробности: [docs/03-architecture.md](../docs/03-architecture.md).
