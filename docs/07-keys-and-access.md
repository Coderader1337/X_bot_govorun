## Что должно быть у заказчика, чтобы жить без разработчика

Недостаточно «отдать `.env`». Нужны **кабинеты**:

1. **developer.x.com** — свой (или явно переоформленный) проект/приложение, биллинг карт, возможность перевыпустить Consumer/Bearer/Access tokens.
2. **Аккаунт X, который постит** — логин, пароль, 2FA. Токены привязаны к нему; смена пароля X не всегда инвалидирует token, но смена приложения — да.
3. **platform.deepseek.com** — свой ключ и баланс.
4. **SSH на VPS, где крутится только этот бот**, либо выделенный пользователь без доступа к RAG/почте.
5. **Git-репозиторий** на организации заказчика.

Пока пункты 1–3 не подтверждены логинами заказчика, независимость **не выполнена**: ключи есть, «явок» может не быть.

## Проверка независимости (чеклист на созвоне)

- [ ] Заказчик логинится в developer.x.com без разработчика и видит то же приложение.
- [ ] Заказчик видит расход кредитов и может оплатить (сейчас прод стоит на `402 credits depleted`).
- [ ] Заказчик логинится в X-аккаунт постинга (не developer-only).
- [ ] Заказчик логинится в DeepSeek и видит ключ / может выписать новый.
- [ ] xAI: либо кабинет заказчика, либо ключ удалить из `.env` и поставить `GROK_FALLBACK_ENABLED=0`.
- [ ] SSH: отдельный пользователь `movetorussia-twitter` **или** отдельный VPS. Root общего сервера заказчику этого проекта не отдавать.
- [ ] GitHub: repository transfer / новый remote. История текущего git содержит секреты — см. [HANDOVER.md](HANDOVER.md).

## Ротация (делать до или сразу после передачи)

Порядок: новый секрет в кабинете → новый `.env` на VPS → `docker compose up -d reply-bot` (чтобы контейнер перечитал env) → отозвать старый ключ.

Ротировать обязательно, потому что в git-истории уже были:

- полный `.env_reserve.txt` (X + DeepSeek + xAI) в коммите `ee0ed37`
- пароль root VPS в `scripts/sync_to_vps.py` / `reset_vps_db.py` (коммиты `c430890`, `01ae774`)

Старый пароль из скриптов на 31.08.2026 **уже не подходит** к SSH; актуальный живёт в локальном `.env` как `VPS_PASS`. Оба считаются скомпрометированными для круга, у кого есть clone.

После ротации не коммитить `.env`. Скрипты выкладки читают `VPS_PASS` из окружения.
