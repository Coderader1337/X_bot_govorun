# Что требует разработчика

Админки нет. При живых кредитах X и непустой очереди бот постит сам.

## Оператор может сам

| Задача | Частота |
|---|---|
| Пополнить кредиты X при `402` | По исчерпании |
| Проверить посты в X | 1–2 раза в неделю |
| Баланс DeepSeek | Редко |
| Прочитать лог по [05-vps-deploy.md](05-vps-deploy.md) | По инциденту |

## Нужен разработчик

| Задача | Частота |
|---|---|
| Сменить `--tweet-id` / `--db-id` + rebuild | Раз в кампанию |
| Сброс `discovery_complete`, чтобы добрать ответы | По мере надобности |
| Текст, стоп-слова, geo, промпт DeepSeek | 1–3 месяца / по качеству |
| Видео | Смена креатива |
| `DAILY_POST_LIMIT` | Редко (`.env` + recreate) |
| 403 на media | По инциденту |
| Ротация ключей | Handover и при утечке |
| Переезд на отдельный VPS | Разово: текущий сервер общий |

После стабилизации: **0–2 часа в месяц**. Пики — новый parent и 402/403.

**Очередь пуста, discovery=done** — кредиты кончились или твит вычерпан: биллинг X, новый tweet-id или сброс флага.  
**402** — не рестартовать, пополнить кредиты. Failed сами не вернутся.  
**403** — права Read+Write+media; бот паузит 5 часов.

Не делать: `reset_vps_db.py --yes` на живой очереди, `--deploy-db` на прод-БД, рестарт ради логов, любые команды вне `/opt/movetorussia/twitter_agent`.
